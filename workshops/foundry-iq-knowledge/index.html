    Module 0 What Foundry IQ is

    Foundry IQ is agentic retrieval over a knowledge base — it grounds an agent's answers in your curated content and returns source citations.

    Docs: What is Foundry IQ FAQ

    ▸Knowledge base, knowledge source, retrieval~5 min

    Intent: learn the three building blocks before you build.

    • Knowledge source — where content comes from (e.g. a Blob/ADLS Gen2 container of documents).
    • Knowledge base — the retrievable index in Azure AI Search built over one or more sources.
    • Agentic retrieval — the agent plans and runs retrieval to ground its answer, with citations.
    ReusableKnowledge bases can be called from Foundry Agent Service, Microsoft Agent Framework, or any app that uses the Azure AI Search knowledge base APIs.
    StatusFoundry IQ is partial GA — API-level GA, portal access remains preview.

    Module 1 Prepare the ContosoMart documents

    Foundry IQ retrieves from unstructured content. Land the three sample docs where a knowledge source can read them.

    Docs: Blob knowledge source

    ▸Upload the docs to Blob/ADLS~6 min

    Intent: give the knowledge source something to index.

    Create (or reuse) an Azure Storage account and a container contosomart-docs, and upload the three files from this lab's data/ folder:

    • returns-policy.md — the returns & refund policy.
    • supplier-contract.md — the Highland Roastery agreement (covers Yirgacheffe).
    • ops-runbook.md — the cold-store operations runbook.
    Why documentsThese are exactly the questions the Fabric data agent can't answer — it doesn't support .pdf/.docx/.txt/unstructured content.
    Expected resultThree documents sit in contosomart-docs, ready to index.

    Module 2 Create the knowledge base

    Build a blob knowledge source, then a knowledge base over it in Azure AI Search.

    Docs: Create a knowledge base Blob knowledge source

    ▸Build source + knowledge base~12 min

    Intent: turn the documents into a retrievable knowledge base.

    • Create a blob knowledge source pointing at contosomart-docs.
    • Create a knowledge base named contosomart-knowledge over that source in your Azure AI Search service.
    • Wait for indexing to complete, then run a test retrieval such as "returns window for opened beans."
    Expected resultA retrieval test returns passages from returns-policy.md with a citation to the source document.
    NetworkingFor private setups, knowledge sources and the search service support private endpoints — see the Foundry IQ private-retrieval tutorial.

    Module 3 Connect the knowledge base to the concierge

    Add a project connection to the knowledge base, then attach it as knowledge on the agent.

    Docs: Connect IQ to agents Add a connection

    ▸Connect & attach knowledge~10 min

    Intent: let the concierge retrieve from the knowledge base.

    • In the contosomart project, add a connection to your Azure AI Search knowledge base.

    Routing: for sales/inventory/customer numbers use the Fabric tool;
for returns, supplier contracts, and operations runbooks use the knowledge base.

    For buildersPrefer a Foundry IQ knowledge base over the file-search tool when the content is curated org knowledge you want grounded with citations.

    Module 4 Ask document questions — with citations

    Module 5 Choose the right grounding

    Foundry IQ, file search and memory solve different problems — pick deliberately.

    Docs: FAQ

    ▸IQ vs file search vs memory~5 min
    Use When
    Foundry IQ Ground answers in curated org content with citations (this lab).
    File search A few user-provided files during an interaction; lighter weight.
    Memory Persist user/agent context across sessions.
    NoteFoundry IQ knowledge sources and Microsoft Copilot knowledge sources are not interoperable — the concept is the same, the supported sources differ.
